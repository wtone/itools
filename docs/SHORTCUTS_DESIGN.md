# 快捷键与剪贴板面板设计

延续原生系统字体、蓝色强调和系统浅深色背景。独立 NSPanel 置于 floating 层，采用 nonactivatingPanel + canJoinAllSpaces/fullScreenAuxiliary，使呼出不必先跳回主窗口。面板捕获呼出时的目标应用，复制 / 关闭时返回；自动粘贴前再次检查目标 PID、存活及剪贴板 changeCount。

竖向 530×670 pt，横向 1020×420 pt，均按鼠标所在显示器 visibleFrame 缩小和限制位置；负坐标显示器沿用真实原点。顶部为历史 / 短语切换与布局菜单，中间搜索和类型 / 分组，正文使用懒加载列表 / 卡片，底部提供明确的复制 / 粘贴和键盘说明。首九项编号固定跟随筛选结果，箭头滚动跟随选中 ID。

快捷键指南 810×700 pt，与设置共用搜索、功能分类与实时绑定数据。常用入口排在前面，设置模式切换为按键录入与清除。未分配项可从指南执行；系统注册失败与未配置分开显示。未配置并不代表该功能缺失。

绑定保存在版本化本机配置中，显式清除与未覆盖默认值分开保存。更新版本时用户绑定优先于新增默认组合；未知未来 ID 保留。设置新组合先验证冲突并尝试系统注册，成功才移除旧注册与持久化；失败保留原设置。录入器只接收当前录入视图的按键，不使用全局键盘监听。

剪贴板窗口的 local NSEvent monitor 仅在打开期间存在，限制到本窗口。搜索编辑状态和 IME marked text 优先于数字 / 回车快捷操作。面板关闭、失焦或释放时移除监听。与旧主页面共用 ClipboardService，不复制第二套历史数据库；图像 / RTF / 文件 URL 保留原表示。

验证：核心规则测试，加上真实窗口 key 状态、NSEvent 路由、独立 NSPasteboard 往返和自己的 NSView 导出。Carbon 自检只发送本应用事件，等待主队列实际分发，不向用户应用注入按键。真实辅助功能粘贴、原生全屏与多显示器组合仍列为人工验收项。
