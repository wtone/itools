# iTools 快捷面板设计

基于用户提供的 State 截图，保留“顶部状态卡片 / 系统应用快捷行 / 圆形操作网格 / 开机时间”的层级。原生 NSPopover，宽 540 pt，按当前屏幕可用高度缩短，内容可滚动。左键工具箱或任一指标打开；右键工具箱保留文字菜单。

颜色沿用 iTools：系统浅色底约 #F5F5F7、深色底约 #252528、文字跟随系统 #202124 / #F5F5F7、强调蓝 #265CCC、图表青 #30B0C7、启用状态绿 #248A3D。背景采用 macOS 原生材质，不叠加模拟光影。字体使用系统中文/SF，数据采用等宽数字；标题 15、指标 23、按钮 11、次要说明 10 pt。

状态卡片两列，CPU/内存有近期曲线，GPU/磁盘/网络/传感器用紧凑读数；不补造未知数据。快捷网格五列，图标圆底、文字位于下方，启用开关有明确指示。系统应用用原应用图标，不增加装饰性标题。增加/减少通过可保存的清单与上下排序完成。

主要操作沿用已有服务。需失焦的截图/锁屏/屏保/窗口操作先关闭面板再运行。清洁模式仅用户主动启动时创建按键过滤，Esc 长按两秒或超时一分钟自动退出。系统外观/Dock/菜单栏通过 System Events 的脚本字典接口操作，拒绝自动化授权时显示错误。
