# 截图与长截图（2026-10-08）

## 区域截图工作区

区域截图不再在松开鼠标时结束。开始后先隐藏 iTools 内容窗口，以原始分辨率冻结各显示器画面，再覆盖灰色半透明蒙层；可在任意一个显示器内拖动框选，支持反向拖动和 Retina / 普通屏混用。

框选后保留亮色选区、八个边角控制点和浮动工具栏。拖动边缘或控制点调整大小，选择/移动工具下拖动空白区域移动选区；标注工具下按住空格也可移动。工具栏提供框、圈、箭头、线条、画笔、T 文字、填充色块、不透明遮盖、颜色、粗细/字号、撤销/重做和重新框选。直接悬停标注即可修改，双击文字在图片内编辑，失焦保存。移动或扩大选区会重新露出冻结原图，标注保留完整屏幕像素坐标。

选区与标注共用编辑历史，调整选区或重新框选均可 ⌘Z 撤销、⇧⌘Z 重做。框选前按空格切换窗口选择，使用冻结画面的最前方窗口边界。Enter、双击选区空白处或「完成并复制」完成；文字编辑期间 Return 输入换行，⌘Return 退出文字编辑。Esc 在文字编辑中取消当前文字修改，其余情况取消截图。取消不替换原图片或剪贴板。

完成时先提交原位文字及输入法组词，再按选区裁取原始像素，保存并复制含标注的 PNG。工具栏、蒙层、边框和控制点不进入输出；主窗口保留可编辑标注对象。一个选区限制在一个显示器内，显示器布局变化时取消会话。全屏截图和连续长截图继续使用各自的流程。

## 连续长截图

参考 Shottr 的一次框选与自动/手动滚动方式，以及 CleanShot X 的悬浮操作和原生编辑器：

- https://shottr.cc/kb/scrollingcapture
- https://cleanshot.com/features

点击「长截图」，所有显示器同时进入框选状态，可在任意屏幕拖动框选完整的滚动内容。选区保持锁定且透明，其他区域（包括其他显示器）持续保留半透明灰色蒙层，直到完成或取消；暂停时也保留蒙层。蒙层不拦截鼠标，选区中的操作会传给目标应用。悬浮条提供自动/手动模式、慢速、开始、暂停/继续、完成和取消；全局 Esc 取消。蒙层、工具条与边框从捕获画面中排除，即使工具条与选区重叠也不会进入最终图片。

自动模式通过已有辅助功能/事件发送授权向目标应用发送滚动事件；无授权时默认手动模式。自动滚动到底后结束；未检测到任何滚动时转为手动模式并继续采样，明确提示尚未追加滚动画面。手动模式以固定选区持续采样，无需再次选区或切回主窗口。在其他屏幕操作或切换前台应用不会停止捕获；目标选区中心被其他应用窗口遮挡时自动暂停，恢复后继续。显示器变化、窗口退出、大小或时间达到限制时暂停或保留已验证结果。

增量拼接使用原生 RGBA 像素列分区匹配，排除边缘滚动条和固定侧栏，用非平坦内容行确定位移，并用像素误差与各列一致性区分重复卡片中的独立内容；支持静态顶部/底部区域去重。重复帧不增加高度，上滚、动态页面、滚动过快或无可信重叠不盲目追加。自动对齐失败先重试，再切换手动持续采样；保留最后一张有效结果，提示回滚少许后慢速继续。输出限制 8000 万像素，捕获时长最多 180 秒。当前仅支持纵向向下滚动。

完成前补采选区的最新画面；已有采样在进行时先等待再补采，避免完成操作丢掉最后一段。多帧结果自动保存 Long-*.png、复制到系统剪贴板并打开编辑器。只有首帧时按钮显示「保存当前区域」，保存为 Shot-*.png，并明确提示尚未追加滚动画面。取消不改动已有图片和剪贴板。截图与录屏仍沿用现有权限和快捷键。

## 可编辑标注

选择/移动、画笔、线条、矩形、椭圆、箭头、文字、填充色块、不透明遮盖、裁剪。标注为带稳定 ID 的独立对象。

悬停对象时自动显示选择框和控制点，可直接拖动，无需切换「选择与移动」。移到空白区域自动恢复之前的绘制工具；按 Option 可在已有标注上继续绘制，裁剪工具保持独立操作。箭头和线条可拖端点，其他对象可拖四角控制点。文字拖角调整字体大小；点击「T」在图片中输入多行文字，双击已有文字直接原位编辑，光标定位在点击处。点击其他位置或窗口失焦时保存，Esc 取消本次文字编辑，⌘Return 保存；没有单独的文字弹框。也可调整颜色/粗细、删除。方向键微调位置，Shift 加方向键每次移动 10 像素。

每次拖动或完整文字编辑只生成一步撤销。文字输入期间 ⌘Z 撤销输入；退出文字编辑后 ⌘Z 撤销对象修改，⇧⌘Z 重做。清空文字删除对象，可撤销恢复；复制、导出时自动提交最新文字。裁剪只改变背景可见范围并平移对象坐标，不将标注烧入背景；撤销可同时恢复原图与标注位置。最多保留 60 步编辑历史。编辑区可滚动、放大并回到适合宽度。
