# 功能矩阵与实现边界

状态以当前源码实际实现为准。**内置**表示已有实现，不代表已覆盖所有机型的实机验收；**外部**表示通过系统或网页服务完成；**未实现**表示没有相应的内置实现，不用按钮或模拟数据掩盖差距。

0.12.3 已移除应用集成页面、四款参考应用的检测与启动、图片交接及关联快捷键。iTools 已内置的功能独立运行，不依赖这四款软件。下表继续以它们作为能力参考，未实现的功能不会因移除入口而变成已实现。

## 对应 iShot 的内置实现

| 能力 | 当前实现及边界 |
| --- | --- |
| 区域/窗口/全屏/延时截图 | 内置；系统选择器，Space 选窗口；全屏按钮截主屏 |
| 常规标注 | 内置画笔、矩形、箭头、文字、不透明遮盖，撤销尚未导出的标注 |
| 裁剪 | 内置；裁剪时合并当前标注，原始截图文件保留 |
| 贴图 | 内置浮动窗口，可移动、缩放、关闭；暂无透明度滑块和滚轮缩放 |
| 取色 | 内置系统放大镜，复制 HEX；暂无格式配置与颜色收藏 |
| OCR / 二维码识别 | 内置 Vision，离线中英文；结果可复制 |
| 截图翻译 | 外部网页翻译；用户确认后发送 Google，不是内置翻译引擎 |
| 长图 | 内置多图按文件名纵向拼接；**未实现自动滚动捕获和重叠消除** |
| 录屏/录音 | 内置 AVCapture，主屏或框选区域，音频输入设备、帧率、鼠标、暂停/继续 |
| 系统声音 | 通过用户安装的虚拟音频输入；尚未实现 ScreenCaptureKit 系统音频后端 |
| 视频/GIF | 内置时段裁剪、720p 导出、≤30 秒 GIF；没有完整时间线 |
| 带壳、多窗口组合、丰富贴纸、智能变焦、马赛克跟踪 | 未实现；当前没有对应的内置能力 |

## 对应 iRightMouse 的内置实现

| 能力 | 当前实现及边界 |
| --- | --- |
| 访达右键入口 | 内置 Finder Sync 扩展；需用户启用；0.6.0 优先系统联动，后台直接执行，所需参数 / 确认 / 结果使用独立窗口，不打开主界面 |
| 新建文件 | 内置文本类格式及导入真实模板；不使用空文件伪装 Office / Adobe 文档 |
| 常用目录、路径复制、终端/应用打开 | 内置；终端使用 Launch Services，不拼接 shell 命令 |
| 复制、移动、剪切/粘贴 | 内置；同名冲突报错、不覆盖；标准文件剪贴板与 Finder 联动，粘贴时读取当前剪贴板，避免旧剪切记录误用 |
| 重命名 | 内置前缀 + 数字；预览确认，两阶段改名，失败尝试回滚 |
| 隐藏/显示、扩展名、校验、ZIP/7z/AES、废纸篓 | 内置；压缩支持多选、快速/标准/最大压缩、密码及校验后移到系统废纸篓 |
| 图标、桌面替身、AirDrop、同名文件夹、解散文件夹、彻底删除 | 0.2.0 内置；文件改动前预览/确认，冲突拒绝覆盖 |
| 文件名乱码、所有者写权限、磁盘扫描 | 0.2.0 内置；可逆编码候选预览、非递归写权限、逻辑大小扫描 |
| 复杂菜单编辑、系统级文本服务、众多格式转换 | 未实现；当前没有对应的内置能力 |
| 自动注册快捷键覆盖 Finder ⌘X / ⌘V | 未实现；当前使用右键/主程序按钮 |

截图中的每一项及安全边界见 [右键菜单对照](FINDER_MENU.md)。

## 对应 iCopy 的内置实现

| 能力 | 当前实现及边界 |
| --- | --- |
| 历史类型 | 内置文本/RTF/HTML/图片/多文件路径；文件原件不复制入资料库 |
| 搜索、收藏、分组 | 内置；当前搜索内容与来源应用 |
| 粘贴、纯文本、队列 | 内置；粘贴只在用户操作后发送 ⌘V 给先前应用 |
| 存储与保留 | 本地 JSON，条数/天数规则，100 MB 普通历史容量，收藏保护 |
| 隐私 | 默认不监听，排除应用、保密类型过滤，无上传 |
| 快捷回复 | 内置短语、分组、日期/时间/剪贴板变量 |
| 导入导出 | 内置历史 JSON；暂无短语文件导入和加密导出 |
| 独立浮动面板 | 内置横向卡片 / 竖向列表，鼠标所在显示器附近呼出，可拖动，支持分类、数字选择、复制或粘贴 |
| 可配置快捷键与指南 | 内置全局按键录入、冲突检查、搜索、清除与恢复，以及独立操作指南 |
| iCloud、文字插入光标定位、全局触发词自动展开、复杂附件短语 | 未实现；剪贴板历史与短语目前仅在本机使用 |

## 对应 State 的内置实现

| 能力 | 当前实现及边界 |
| --- | --- |
| CPU/内存/交换空间 | 内置 Darwin counters，每 2 秒采样；图表保留 60 个样本 |
| 磁盘 | 用户所在卷总量/可用量；不是逐磁盘 I/O 仪表 |
| 网络 | 当前启用的 en* 物理接口吞吐量，排除 VPN/回环，重置时跳过异常差值 |
| 电池、开机时间 | 电量、充电状态、容量健康、循环、系统 uptime |
| 温度/风扇 | Intel SMC 常见键只读，每 10 秒；失败显示不可用，不控制硬件 |
| GPU | 驱动提供的使用率与曲线；多显卡取最高值，缺失不记为零 |
| 菜单栏 | CPU、内存、GPU、磁盘已用比例、双向网速、温度、风扇，独立开关/立即生效/自动保存 |
| 快捷面板 | 0.3.0 内置实时状态卡片、5 个系统应用入口、23 个可选操作、增减/排序、浅深色与高度适配 |
| 进程排名、高级图形组件、温度告警、手机远程监控、硬件控制 | 未实现；当前只读硬件数据，不控制硬件 |

## Vorssaint 设计取舍

采用一个菜单栏入口、多个独立服务、模块启停、按操作申请权限、本地存储的思路。额外内置窗口分屏、防休眠、便笺与链接清理。每应用音量、音频路由、Dock 悬浮预览、鼠标滚轮/键盘增强、清理卸载、Homebrew 管理、外接显示器控制尚未移植；不把原项目“只改架构标志”当作 Intel 适配。

原项目自述的最低条件和功能参见 [Vorssaint README](https://github.com/vorssaint/vorssaint-utils/blob/main/README.md)。这里没有复用其 GPL 源码。
