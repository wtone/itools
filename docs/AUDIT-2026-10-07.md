# 功能与界面检查 · 2026-10-07

本轮使用 Apple Silicon、macOS 15.8.1、Xcode 16.4 / Swift 6.1.2，检查当前七个页面、核心服务和原生系统交接。完成 Intel + Apple Silicon 通用发布版构建与本机开发证书签名；最低部署目标为 macOS 12。编译兼容性不等于 macOS 12 或 Intel 实机验收。

## 修复与优化

- 新截图、导入图片、拼接图片清除旧 OCR；图像任务繁忙时防止切换图片；取消截图按此前窗口状态恢复，失败时恢复可见错误提示。
- 拼接按照真实像素尺寸处理 Retina 图片，避免按逻辑尺寸缩小；分配失败返回明确错误。
- 快捷短语支持面板分组与搜索的交集筛选，切换面板模式清除旧筛选；空白名称/正文不能保存。保存与删除先成功写入再更新界面，写入失败保留输入和原列表。
- 视频裁剪区分取消与无效秒数，检查范围、非有限数和视频时长；不支持 MP4 导出时提示原因。音频设备断开时明确提示，不静默改用另一个设备；导出期间退出会被阻止。
- 二维码修改内容后清除旧预览，显示 2000 字节限额，并反馈生成、复制、保存结果。
- 未提供网络或内存读数时显示不可用；传感器说明反映实际机型支持情况。
- 菜单栏采用紧凑的 AppKit 原生文字，常见读数范围预留宽度；首次设置可见初始位置，后续保留用户拖动位置，并提供「恢复可见位置」。实桌面截图已确认 CPU、内存、GPU、双向网速可见；设置预览与实际格式一致。
- 主界面改为浅深色中性色板、紧凑品牌区、统一留白和圆角，保留原生窗口控件。总览剪贴板入口直接呼出面板，快捷键文案读取用户实际配置；⌘1–⌘7 切换页面。
- 自检资料按输出目录隔离；Finder 偏好测试按本机架构编译，避免在 Apple Silicon 上无必要依赖 Rosetta；补齐登录项测试脚本可执行权限。

## 尚未实证的边界

- 两次发布版自检分别出现剪贴板初始焦点失败、快捷键面板录入未保持激活；完整重检及独立三模式焦点检查通过；最终版完整重检也通过，并以真实原生点击确认录入、按键验证与取消正常。尚未确定偶发失败原因，不能宣称已修复全部焦点问题。
- 本机拥挤菜单栏的四项读数已实测可见；七项全开及其他分辨率/机型仍受可用空间限制。
- 麦克风未授权，未实际录制用户屏幕或音频；录屏/录音、暂停恢复、设备热插拔、视频压缩/GIF 的完整媒体端到端链路尚需实机验收。
- 窗口跨应用控制、真实粘贴到其他应用、不同显示器与 Spaces、休眠唤醒、其他机型传感器未穷举。
- 系统脚本已编译；没有执行锁屏、清空用户废纸篓、系统外观切换或向 AirDrop 接收者发送文件。
- 对未实现的自动滚动长截图、原生系统音频等高级能力，继续遵守 `FEATURES.md` 的边界，不将它们算作已完成。

用户资料不参与自动功能检查；使用合成文件、测试状态目录及私有剪贴板。额外的桌面验证仅截取顶部菜单栏，没有截取工作区内容。原有登录项与菜单偏好保留。

菜单栏位置实现参考原生开源应用的 [AppKit 状态项保存位置实现](https://github.com/jordanbaird/Ice/blob/main/Ice/MenuBar/ControlItem/ControlItem.swift)。仅为 iTools 自身的新 autosave 名称初始化位置，不每次重设用户位置；此持久化键属于 macOS 实现细节，当前系统已实测，未来系统仍需回归。
