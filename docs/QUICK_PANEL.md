# 顶部快捷面板 · 0.3.0

## 打开与自定义

- 左键点击顶部 iTools 工具箱图标，或 CPU / 内存 / GPU 等任一指标，弹出快捷面板。
- 右键点击工具箱图标，保留原来的文字菜单。
- 点击右上角「编辑」，可勾选/移除操作，用上下箭头调整顺序；立即保存，重开应用仍保留。全部取消后不会擅自恢复默认。
- 可单独关闭状态卡片；「设置 → 顶部快捷面板」也能调整入口。
- 面板宽 540 pt，高度随屏幕可用空间调整，内容超出时可滚动。点击空白处、右上角关闭或 Escape 退出。

## 面板内容

- **实时卡片**：CPU（含用户/系统占比与曲线）、内存与曲线、GPU、磁盘可用空间、双向网速、本机物理接口 IPv4、温度/风扇。未知或暂停时显示「—」。
- **系统应用**：系统设置、磁盘工具、系统信息、控制台、活动监视器。
- **默认 15 项操作**：防止自动休眠、系统深色模式、锁屏、保持亮屏、进入屏保、清洁屏幕、清洁键盘、桌面遮罩、自动隐藏 Dock、自动隐藏菜单栏、区域截图、屏幕文字识别、剪贴板与短语、访达工具、显示器设置。
- **另外 8 项可选操作**：左半屏、右半屏、最大化、还原窗口、屏幕取色、录屏与录音、清空废纸篓、Dock 设置。
- **动态入口**：录制时显示「停止并保存」；防休眠时显示结束时间和停止按钮。
- **底部**：开机时间、iTools 设置、剪贴板记录开关、粘贴队列、退出应用等。

## 操作行为与边界

| 操作 | 实现 |
| --- | --- |
| 防止自动休眠 | 原生 IOPMAssertion，默认 30 分钟；开盖场景。不保证合盖运行，不写永久电源配置 |
| 保持亮屏 | 同时持有系统自动休眠及显示器休眠断言；与防休眠共用会话，停止/退出时释放 |
| 系统深色、Dock/菜单栏自动隐藏 | 通过系统自带 System Events 脚本字典操作；首次可能需要「自动化」权限，失败不会伪装成切换成功 |
| 锁屏 | 发送 macOS 的 Control-Command-Q 快捷键，需要辅助功能权限 |
| 屏保 | 启动系统 ScreenSaverEngine；屏保是否立即要求密码由系统设置决定，不能替代锁屏 |
| 清洁屏幕/键盘 | 所有显示器显示清洁面板，临时拦截普通按键；两者使用相同保护机制，以提示对象区分 |
| 清洁退出 | 按住 Esc 两秒、点击结束、60 秒超时、系统休眠/显示器变化/切换应用/会话锁定、事件拦截失效或退出应用时清理 |
| 清洁限制 | 不保存或记录输入内容；电源键、媒体键和部分系统保留快捷键不保证拦截。此功能不是安全锁 |
| 桌面遮罩 | 在桌面图标上方放置临时窗口，优先加载当前壁纸；文件本身不改名、不隐藏、不移动，退出恢复。动态壁纸可能显示为静态图/系统底色 |
| 清空废纸篓 | 需确认后由 Finder 执行，可能请求自动化权限；不可撤销 |
| 显示器 / Dock 设置 | 打开对应系统设置面板，旧系统不支持定位时仍可进入系统设置 |

参考截图中的「合盖不眠」「隐藏刘海」「锁定 Dock」没有伪装成可用开关：当前实现提供防止自动休眠、桌面遮罩与 Dock 设置入口。Intel Mac 的适配目标不需要刘海处理；完整禁用合盖睡眠和锁定 Dock 布局不属于本版实现。

## 验证

- 51 项核心测试通过，包括原有文件/剪贴板/菜单栏测试；新增入口增减、排序、空配置、未知配置、设置保存、测试隔离、Esc 连续长按与超时策略测试。
- 原生面板实际打开/关闭、浅色/深色/编辑界面/清洁提示视图通过自检；仅渲染 iTools 自己的窗口。
- 系统操作脚本通过语法与字典编译检查，没有在验证时执行锁屏、系统外观切换或清空废纸篓。
- 清洁模式的实际按键拦截仍需用户授予辅助功能后在本机验收，自动化未拦截用户输入。
- 主程序、Finder 扩展与压缩组件面向 Intel x86_64 / macOS 12.0 编译，实测机器为 macOS 13.7.8。

接口依据：本机 macOS 的 SystemEvents.sdef（appearance / dock preferences）、Finder.sdef（empty trash），以及 Xcode SDK 的 IOPMLib.h；IOPMLib 明确说明空闲休眠断言不覆盖合盖触发的休眠。
