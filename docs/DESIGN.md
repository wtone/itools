# iTools 设计与架构

面向继续使用 Intel Mac 的用户：一处管理、按需运行、本机处理、低负担。最低部署 macOS 12，避免 SwiftUI NavigationSplitView、MenuBarExtra 等新版系统依赖。开发机为 Intel / macOS 13.7.8 / Swift 5.9.2。

## 界面

色板：雾白 #F5F7FA（工作区）、石墨 #202938（文字）、钴蓝 #275DCE（交互）、青绿 #168878（运行状态）、浅钢灰 #E6EBF2（分隔）、琥珀 #A56A16（需处理）。使用 macOS 系统字体与中文系统字体；标题 28、栏目 18、正文 13、辅助 11。数据使用等宽数字，不给所有内容加装饰卡片。

布局：固定 208px 工具侧栏，右侧统一页面标题与功能操作。主页以“截取、复制、整理、观察”四个工作入口为主；监控图表、剪贴板列表和截图画布采用各自合适的结构。全界面左对齐，原生焦点、深色模式、键盘快捷键与系统对话框。

审视：这是一款常驻菜单栏的原生桌面工具，工作区不使用网页式 hero、渐变海报或营销统计。表达重点放在系统原生控件、清楚的可用状态和少量模块颜色。

## 模块边界

- IToolsCore：可测试的剪贴板模型、配额策略、文件操作、窗口几何、URL 工具、能力定义。
- ITools：SwiftUI 界面，AppKit 窗口/菜单栏，按需启动的各服务，统一错误报告。
- SystemBridge：Darwin 主机统计、网络接口计数和只读 Intel SMC。读取失败返回不可用，不伪造温度或风扇数据。
- FinderSync：独立 app extension，菜单通过 itools://finder 发送操作与文件 URL；文件操作在主程序处理。
- CompanionRegistry：通过用户选择的本机 app 路径连接 iShot / iRightMouse / iCopy / State。原软件在自身进程运行，其授权和功能边界不变。

运行：剪贴板需用户开启后才监听；监控可关闭并释放计时器；录制仅显式启动；权限按操作请求。全局快捷键用 Carbon RegisterEventHotKey，无需捕捉全部键盘输入。截图、文本识别、标注与文件操作都在本地。

扩展不是下载执行任意代码的插件系统。新增原生能力按 CapabilityCatalog 声明版本/权限/实现情况，并添加服务、界面、测试。需要商业软件完整能力时连接用户安装的原应用，不重新分发其二进制或私有资源。
